# Security Policy

## Supported version

Forge for Pi 1.0.2 is the supported public release.

## Reporting

Do not include secrets, credentials, session files, or private traces in a report. Share a minimal reproduction and sanitized logs through the repository's private security-reporting channel when it is available.

Forge telemetry is opt-in (`FORGE_FOR_PI_TRACE=1`) and writes local metadata only. Review local files before sharing them.
